## 📖 Module Descriptions

### 1. `documentation/`
Detailed academic documentation covering all aspects of system design, research context, mathematical formulations, database normalization, and user interaction workflows.

### 2. `presentations-and-papers/`
Slide decks and publication-ready formatted PDFs suitable for major project defense presentations, conferences, and technical reviews.

### 3. `technical-audit-records/`
Complete engineering audits detailing exact code references, line numbers, middleware configurations, security considerations, and API request/response specifications.

### 4. `evaluation-and-evidence/`
Empirical experimental results validating the accuracy, calibration, and out-of-distribution detection capabilities of the deep learning plant pathology pipeline.
